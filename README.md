# pfQuest-Raven

[pfQuest](https://github.com/shagu/pfQuest) database extension for **[RavenCraft](https://ravencraft.io)** — *Mysteries of Azeroth*.

Requires the latest [pfQuest](https://github.com/shagu/pfQuest). Built from Turtle DB + RavenCraft / CinderQuestieData merges.

## Install

1. Install **[pfQuest](https://shagu.org/pfQuest)**
2. Copy the folder `pfQuest-Raven` into `Wow\Interface\AddOns`
3. Restart WoW / `/reload`

## Tools

Scripts in `tools\` rebuild drop sources and missing quests from CinderQuestieData into `db\`.
